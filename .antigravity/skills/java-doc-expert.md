# Skill: Java Documentation Expert

## Descrição
Capacidade de gerar Javadoc técnico e preciso em português para métodos e classes de serviço.

## Critérios de Execução
1. Identificar todo método público em classes de serviço (`@Service`) ou classes utilitárias (subpackage `util`), definições de métodos em interfaces e métodos públicos em enums.
   1.1. Sempre que um dos métodos identificados for criado, ou se já existente, tiver sua assinatura, comportamento ou retorno alterados, deve-se escrever ou atualizar o Javadoc do mesmo.
2. Escrever Javadoc em **Português (Brasil)**.
3. Descrever parâmetros (`@param`), retorno (`@return`) e exceções (`@throws`) de forma clara.
4. Usar `@link` para referenciar outros métodos ou classes.
5. Garantir que a explicação reflita a lógica de negócio implementada.
